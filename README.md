A program that writes exactly one letter, A for coffee, to `/output/entry.txt`,
for the make.fun competition
[One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

Run it with Python 3:

```
python3 main.py
```

It writes the letter below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The letter is 1 character, inside the exactly-1 gate.

## The letter

```
A
```

A is coffee. An agent that works through the night runs on coffee.
